# Ai - Hindi Dubbed Anime Website

**Ai** is a simple and mobile-friendly website where users can watch Hindi dubbed anime episodes with Google Drive links.

## Features

- Homepage with a list of top 10 anime
- Separate episode list for each anime (linked in episode.html)
- Each episode has its own HTML page
- Google Drive links for each episode
- Works well on both mobile and desktop

## How to Use

Visit the website here:  
**[https://aianime.github.io/Ai/](https://aianime.github.io/Ai/)**  
(*Replace `aianime` with your actual GitHub aianime*)
